======================================================================
四角色卡v5.0修改方案（四层分开版）
======================================================================
修改日期：2026-08-31
修改原因：之前四层分析混在一起、四层向量只有表象层、匹配一次性看四层，步子迈太大。
核心原则：四层分开分析、四层分开存放、倒过来逐层匹配。
思想层和情感层在金庸里100%存在，必须先从这两层锁定。

======================================================================
一、分析卡v5.0（四层分开分析版）
======================================================================

【核心变化】
之前：四层分析混在一起做，一次性输出四层查询。
现在：四层分析分开做，一层一层分析，每层输出单独的查询，单独存放。

【分析顺序：由外向内】
第一步：表象层分析 → 输出表象层查询 → 存到 第X章_分析_表象层.txt
第二步：结构层分析 → 输出结构层查询 → 存到 第X章_分析_结构层.txt
第三步：情感层分析 → 输出情感层查询 → 存到 第X章_分析_情感层.txt
第四步：思想层分析 → 输出思想层查询 → 存到 第X章_分析_思想层.txt

【每层分析的内容】

第一层：表象层分析（最外层，最粗糙）
- 这一拍表面上发生了什么事？
- 有哪些人、什么地点、什么动作、什么物品？
- 用了哪些具体的词？（人名、地名、物品名、动作词）
- 输出：表象层查询（用具体的词描述表面发生的事）
- 注意：表象层准确率最低，因为原创词（银纹、命元、火灶房等）在金庸里不存在

第二层：结构层分析
- 这一拍的叙事功能是什么？（起承转合中的哪一个？）
- 动作链是什么？（谁先做了什么，谁后做了什么，结果是什么？）
- 这一拍在整个章节中的位置和作用是什么？
- 输出：结构层查询（用动作链和叙事功能描述）
- 注意：结构层准确率中等，因为金庸里相似的动作链很多

第三层：情感层分析
- 这一拍的核心情绪是什么？（紧张、恐惧、荒诞、温暖、悲壮、犹豫……）
- 情绪强度是多少？（1-5分）
- 情绪是怎么变化的？（从什么情绪变成什么情绪？）
- 谁的情绪？主角的？对手的？周围人的？
- 输出：情感层查询（用核心情绪和情绪变化描述）
- 注意：情感层准确率很高，因为金庸里这些情绪普遍存在

第四层：思想层分析（最内层，最核心）
- 这一拍的核心思想/生存哲学是什么？
- 主角的目的是什么？对手的目的是什么？
- 这一拍探讨了什么人性？（怕死、贪婪、执着、尊严、归属感……）
- 这一拍的潜台词是什么？（没有说出口但真正想表达的是什么？）
- 输出：思想层查询（用核心思想和生存哲学描述）
- 注意：思想层准确率100%，因为金庸里这些思想和人性普遍存在

【分析卡输出文件结构】
第X章_分析_表象层.txt —— 16拍的表象层查询
第X章_分析_结构层.txt —— 16拍的结构层查询
第X章_分析_情感层.txt —— 16拍的情感层查询
第X章_分析_思想层.txt —— 16拍的思想层查询

四个文件分开存放，不混在一起。

二、向量卡v2.0（四层向量库分开版）
======================================================================

【核心变化】
之前：只有表象层向量库（45823段），四层查询都在表象层检索。
现在：四层向量库分开，每层单独存放，每层单独检索。

【四层向量库结构】

第1层：表象层向量库（已有，全量45823段）
- 内容：每段原文的直接向量化
- 向量模型：BGE-small-zh，512维
- 索引：FAISS内积索引
- 文件：金庸原文/四层向量/表象层向量库.index + 表象层元数据.json
- 状态：已全量构建，45823段

第2层：结构层向量库（渐进式建设）
- 内容：对每段原文做结构分析（叙事功能、动作链、章节位置），然后向量化
- 向量模型：BGE-small-zh，512维
- 文件：金庸原文/四层向量/结构层向量库.index + 结构层元数据.json
- 状态：待建设，采用渐进式——每次匹配时对候选做结构分析后存入

第3层：情感层向量库（渐进式建设）
- 内容：对每段原文做情感分析（核心情绪、情绪强度、情绪变化、谁的情绪），然后向量化
- 向量模型：BGE-small-zh，512维
- 文件：金庸原文/四层向量/情感层向量库.index + 情感层元数据.json
- 状态：待建设，采用渐进式

第4层：思想层向量库（渐进式建设）
- 内容：对每段原文做思想分析（核心思想、生存哲学、人性探讨、潜台词），然后向量化
- 向量模型：BGE-small-zh，512维
- 文件：金庸原文/四层向量/思想层向量库.index + 思想层元数据.json
- 状态：待建设，采用渐进式

【渐进式建设流程】
1. 表象层全量已有，先用表象层检索得到Top-10候选
2. 对这10个候选，分别做结构、情感、思想三层分析
3. 把三层分析结果存入对应的三层向量库
4. 随着匹配次数增加，三层向量库逐渐完善
5. 当三层向量库覆盖足够多段落时，可以直接用三层查询检索，不再依赖表象层

【检索顺序：倒过来，由内向外】
第一步：思想层检索 → 用思想层查询在思想层向量库检索 → 得到思想层候选
第二步：情感层检索 → 用情感层查询在情感层向量库检索 → 得到情感层候选
第三步：结构层检索 → 用结构层查询在结构层向量库检索 → 得到结构层候选
第四步：表象层检索 → 用表象层查询在表象层向量库检索 → 得到表象层候选

每层检索结果单独存放：
第X章_检索_思想层.json
第X章_检索_情感层.json
第X章_检索_结构层.json
第X章_检索_表象层.json

【过渡方案（三层向量库还没数据时）】
当三层向量库还没有数据时，先用表象层查询检索得到Top-10候选，然后对这10个候选人工做三层分析，存入三层向量库，再用三层查询在这10个候选中筛选。
这样虽然不是全量三层检索，但实现了"四层分开检索"的流程。

三、匹配卡v6.0（倒过来逐层匹配版）
======================================================================

【核心变化】
之前：一次性看四层，从Top-5中选主备选。
现在：倒过来，从思想层开始，一层一层筛选，每一层筛选后候选范围缩小，进入下一层。

【匹配顺序：倒过来，由内向外】
思想层（最核心，100%要匹配）
  ↓ 筛选
情感层（很重要，100%要匹配）
  ↓ 筛选
结构层（重要，尽量匹配）
  ↓ 筛选
表象层（最外层，可以部分匹配）
  ↓ 最终确认
主选/备选

【每一层的匹配规则】

第一层：思想层匹配（权重40%，必须100%匹配）
- 问自己：这段原文的核心思想/生存哲学，和拍子的核心思想/生存哲学，是不是同一件事？
- 是 → 保留，进入下一层
- 不是 → 排除，不进入下一层
- 注意：思想层是最核心的，思想不对的直接排除，不管其他层多像

第二层：情感层匹配（权重30%，必须100%匹配）
- 问自己：这段原文的核心情绪和情绪变化，和拍子的核心情绪和情绪变化，是不是同一种？
- 是 → 保留，进入下一层
- 不是 → 排除，不进入下一层
- 注意：情感层是第二核心，情感不对的直接排除

第三层：结构层匹配（权重20%，尽量匹配）
- 问自己：这段原文的动作链和叙事功能，和拍子的动作链和叙事功能，是不是相似？
- 是 → 保留，进入下一层
- 部分相似 → 标注"结构部分匹配"，可以保留
- 完全不相似 → 排除
- 注意：结构层可以部分匹配，因为金庸里动作链不一定完全一样

第四层：表象层匹配（权重10%，可以部分匹配）
- 问自己：这段原文的表面元素（人、地、物、动作词），和拍子的表面元素，是不是有重叠？
- 是 → 最终确认为主选
- 部分重叠 → 标注"表象部分匹配"，可以作为备选
- 完全不重叠 → 可以排除，也可以保留（如果前三层都匹配的话）
- 注意：表象层是最外层，准确率最低，原创词在金庸里不存在，所以表象层可以部分匹配

【匹配卡输出】
每一拍输出：
- 思想层匹配结果：哪些候选通过了思想层筛选
- 情感层匹配结果：哪些候选通过了情感层筛选
- 结构层匹配结果：哪些候选通过了结构层筛选
- 表象层匹配结果：哪些候选通过了表象层筛选
- 最终主选：通过了四层筛选的候选
- 最终备选：通过了前三层但表象层部分匹配的候选
- 未找到：前三层都没有通过的候选

【匹配度判定标准】
- 完全匹配：四层都通过
- 高度匹配：思想+情感+结构通过，表象部分匹配
- 中度匹配：思想+情感通过，结构部分匹配，表象部分匹配
- 弱匹配：思想通过，情感部分匹配
- 未找到：思想层都没有通过

注意：思想层和情感层必须通过，否则就是未找到。因为这两层在金庸里100%存在，如果这两层都没通过，说明检索或分析有问题。

四、新流程总览
======================================================================

【分析阶段（由外向内，四层分开）】
拍子
  ↓
表象层分析 → 第X章_分析_表象层.txt
  ↓
结构层分析 → 第X章_分析_结构层.txt
  ↓
情感层分析 → 第X章_分析_情感层.txt
  ↓
思想层分析 → 第X章_分析_思想层.txt

【检索阶段（倒过来，由内向外，四层分开）】
思想层查询 → 思想层检索 → 第X章_检索_思想层.json
  ↑
情感层查询 → 情感层检索 → 第X章_检索_情感层.json
  ↑
结构层查询 → 结构层检索 → 第X章_检索_结构层.json
  ↑
表象层查询 → 表象层检索 → 第X章_检索_表象层.json

【匹配阶段（倒过来，由内向外，逐层筛选）】
思想层候选 → 思想层匹配筛选
  ↓
情感层候选 → 情感层匹配筛选
  ↓
结构层候选 → 结构层匹配筛选
  ↓
表象层候选 → 表象层匹配筛选
  ↓
最终主选/备选

【核心原则】
1. 四层分开分析，不混在一起
2. 四层分开存放，每个文件只存一层
3. 四层分开检索，每层单独检索
4. 倒过来匹配，从思想开始，一层一层筛选
5. 思想层和情感层100%要匹配，这两层不对的直接排除
6. 结构层和表象层可以部分匹配
