## 使用说明

### 总体优化时的参考顺序
1. **先看运行记录**：了解实际跑批中的问题和解决方案
2. **再看蒸馏文档**：了解项目核心记忆和经验总结
3. **然后看世界书**：了解多角色协同的通用规则
4. **最后看小助手说明和文档**：了解特定工具和方案的细节
