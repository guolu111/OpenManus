一、核心原则：倒过来匹配是漏斗，不是打分表（模式B专用）
======================================================================

【什么是漏斗】
倒过来匹配不是"四层打分，思想层和情感层100%相似就算高度匹配"。
倒过来匹配是：先用内核层把候选从"表面像"筛成"内核也像"，筛完之后，仍然要回到原文，做最后两关：主体检查+核心动作检查。

每一层的作用是"剔除不对的"，不是"算出多少分"。
层级越往后越严格。
最后一关永远是读原文做两项检查。

【漏斗流程】
    思想层 → 用来排除"主题完全不沾边"的段落
        ↓
    情感层 → 用来排除"情绪走向不对"的段落
        ↓
    结构层 → 用来排除"动作链不同"的段落
        ↓
    表象层 → 用来排除"具体动作和身体细节不对"的段落
        ↓
    读完整原文 → 主体检查 → 核心动作检查 → 选主选

【每一层的具体操作】

思想层（第一层，最宽松）：
- 看这段金庸原文的核心思想，是不是和拍子一样
- 不是 → 淘汰，写"思想层淘汰：核心思想不同（具体原因）"
- 是 → 进入触发条件检查
- 【触发条件检查】（v6.3新增）：思想对齐后，必须再问一句：
  · 拍子的思想是在什么处境下产生的？（战斗后？被抛弃后？修行中？被追杀时？）
  · 候选的思想是在什么处境下产生的？
  · 触发条件一致 → 通过，进入下一层
  · 触发条件不一致 → 淘汰，写"思想层淘汰：触发条件不同（拍子是XXX，候选是XXX）"
  · 举例：拍子是"战斗后怕死"，候选是"被抛弃后孤单"，即使都算"弱者心境"，触发条件不同，淘汰
- 注意：思想层是最宽松的，"人性探讨""生存哲学"这种通用主题很容易通过，所以通过思想层不代表什么，只是没被淘汰而已。触发条件检查是思想层的附加关卡，防止"思想看起来像但处境完全不同"的候选混过去

情感层（第二层）：
- 看情绪和情绪变化是不是和拍子一样
- 不是 → 淘汰，写"情感层淘汰：情绪走向不同（具体原因）"
- 是 → 通过，进入下一层

结构层（第三层，开始严格）：
- 看动作链和叙事功能是不是和拍子一样
- 不是 → 淘汰，或标记"部分匹配，缺什么"
- 是 → 通过，进入下一层
- 注意：结构层是关键分水岭，很多"思想情感对但动作不对"的候选在这里被淘汰

表象层（第四层，最严格）：
- 看具体动作、身体细节、场景细节是不是和拍子一样
- 不是 → 淘汰，或标记"部分匹配，缺什么"
- 是 → 通过
- 注意：表象层是最严格的，完全通过的候选很少，大部分候选在这里被标记"部分匹配"

【通过四层之后】
通过四层的候选（通常0-2个），进入"读完整原文"环节。
读完整原文后，仍然必须做两件事：
1. 主体检查：做这个动作的人，是主角还是对手？
2. 核心动作检查：拍子要的那个动作，原文里真的发生了吗？

两个都通过 → 选为主选。
只要一个不通过 → 换下一个候选。

【未找到的触发条件（P2修正：在结构层/表象层/两项检查触发，不是思想层）】

未找到的触发条件（满足任一即触发）：
1. 结构层筛选后，通过/部分匹配的候选为0；
2. 或者表象层筛选后，通过/部分匹配的候选为0；
3. 或者通过四层的候选，在"读原文+两项检查"后全部不通过。

"思想层都搜不到"不是未找到的标准——思想层是最宽松的，"生存哲学""怕死""执着"这种通用主题，在15本金庸里一定搜得到。思想层都搜不到只说明"金庸里连主题相似的都没有"，极少发生，不是正常的未找到触发条件。

真正决定"未找到"的，是结构层和表象层。
举例：拍十"走火入魔，命从骨头缝里漏"，思想层"修炼=漏命"当然搜得到，情感层"恐惧+真实"也搜得到。但结构层"急修→真气乱窜→倒地→命元漏出"和表象层"骨头缝往外渗东西"，金庸里没有。所以未找到应该在结构层或表象层触发。

未找到时，列出每个候选分别卡在哪一层：
比如"候选1在结构层就淘汰了，因为动作链不同""候选2在表象层淘汰，因为原文没写骨头缝漏命"。

【记录原则（P1修正：只写淘汰者，通过者不写长记录）】
- 每个候选只有在"被淘汰"或"被标记部分匹配"时才写原因
- 通过的候选一笔带过，不需要写"核心思想：XXX→与拍子一致→通过"这种长记录
- 铁律仍然守住——每个淘汰都有原因
- 工作量大幅下降——通过者不用写
- 真正要细看的，是走到"读原文"环节的那0-2个候选
- 输出格式示例：
  ```
  思想层筛选：
    候选3淘汰（核心思想是"师徒温情"，拍子是"互相利用"）；
    候选5淘汰（核心思想是"武功传承"，拍子是"生存哲学"）；
    其余通过，无需逐条记录。
    → 思想层筛选后：通过X个，淘汰Y个
  ```

======================================================================
二、全局匹配等级定义（v6.4新增·五级定义集中管理）
======================================================================

【为什么要有全局定义】
之前"部分匹配""高度匹配""中度匹配"散在各处，没有集中约束，导致放水行为——匹配卡自己写了"无核心动作"仍判部分匹配。v6.4把五级定义集中管理，放在正文核心位置，"部分匹配"准入铁律和定义写在同一块。

【五级定义】

1. 完全匹配
   - 条件：四层全对齐（思想+情感+结构+表象都通过）+主体检查通过+核心动作检查通过
   - 用途：主选
   - 说明：这是最高等级，金庸原文和拍子的核心动作、动作链、情绪、思想都完全对齐

2. 高度匹配
   - 条件：思想+情感+结构对齐，表象部分差异（具体动作或身体细节有出入，但核心动作真实发生）
   - 用途：主选
   - 说明：内核完全对齐，表象有小差异，但不影响核心动作的成立

3. 中度匹配
   - 条件：思想+情感对齐，结构有缺失（动作链不完整，但核心动作真实发生）
   - 用途：备选，不得主选
   - 说明：思想情感对，但动作链有缺失，只能作为备选参考

4. 部分匹配
   - 条件：核心动作真实发生，但动作链/表象大量缺失
   - 用途：备选，不得主选
   - ⚠️ 准入铁律（必须和定义写在同一块）：核心动作没发生，一律"未找到"，禁止用"部分匹配"兜底。"部分匹配"的前提是核心动作发生了但细节有出入；核心动作根本没发生就是未找到。
   - 说明：这是最容易放水的等级，必须严格执行准入铁律

5. 未找到
   - 条件（满足任一即触发）：
     a. 候选池为空（四层检索结果全部为0）
     b. 结构层筛选后，通过/部分匹配的候选为0
     c. 表象层筛选后，通过/部分匹配的候选为0
     d. 通过四层的候选，在"读原文+两项检查"后全部不通过
   - 说明："思想层都搜不到"不是未找到的标准——思想层最宽松，通用主题一定搜得到。真正决定未找到的是结构层和表象层，以及两项检查。

【等级使用规则】
- 主选只能是"完全匹配"或"高度匹配"
- 备选可以是"中度匹配"或"部分匹配"
- "部分匹配"必须先过准入铁律（核心动作真实发生），否则直接判未找到
- 每个拍的最终判定必须明确标注等级，不能只写"主选"不写等级
- 统计汇总时必须按五级分类统计，不能只写"找到X个未找到Y个"

======================================================================
三、三条铁律（违反任何一条即视为失败）
======================================================================

铁律一：每一层只做排除，不做判定
- 思想层通过 ≠ 高度匹配，只是"没被思想层淘汰"
- 情感层通过 ≠ 中度匹配，只是"没被情感层淘汰"
- 只有通过四层+读原文+两项检查都通过，才能叫"主选"
- 禁止走到思想层和情感层就判"高度匹配"
- 禁止写"主选方向"而不给行号和原文

铁律二：最后一关永远是读原文做两项检查
- 通过四层的候选，必须按行号提取完整段落（至少500字），通读全文
- 主体检查：做这个动作的人，是主角还是对手？（防止"接纳者vs被接纳者"主体反了）
- 核心动作检查：拍子要的那个动作，原文里真的发生了吗？（防止"背景介绍当实际发生"）
- 两个都通过才能选为主选
- 禁止用"思想主题一样"替代"核心动作发生"
- 禁止只看三层摘要就做判断——必须自己读原文验证

铁律三：找不到就写"未找到"，列出每个候选卡在哪一层
- 未找到的触发条件（满足任一即触发）：结构层筛选后通过/部分匹配为0，或表象层筛选后通过/部分匹配为0，或通过四层的候选在两项检查后全部不通过
- "思想层都搜不到"不是未找到的标准——思想层最宽松，通用主题一定搜得到
- 必须列出每个候选分别卡在哪一层、为什么
- 禁止标"最近似"硬贴
- 禁止凭记忆仿写原文
- 正常通过率是60%-80%，100%通过意味着偷懒了
- "未找到"不是失败，硬贴一个内核不对的才是失败

三、七步工作流（必须按顺序执行）
======================================================================

第一步：解析分析产物（不做新分析）
读取分析卡给出的四层分开分析报告，对每个拍提取以下信息：
- 原始节拍
- 拍名
- 四层分开分析：
  · 表象层分析（具体动作、身体细节、场景细节）
  · 结构层分析（动作链、叙事功能、人物关系）
  · 情感层分析（核心情绪、情绪变化、人性共通点）
  · 思想层分析（生存哲学、价值观、潜台词）
- 四层分开检索结果：
  · 思想层Top-10候选（含书名、回目、行号、原文前200字）
  · 情感层Top-10候选
  · 结构层Top-10候选
  · 表象层Top-10候选
- 功能画像（3-5条硬条件）
- 验证问题（1-3个是/否问题）
- 排除方向（2-3个不对的场景）

关键规则：
- 这一步是"读取和提取"，不是"重新分析"
- 四层候选可能有重叠，也可能完全不同，都要保留
- 如果分析卡写"可能无对应场景"→ 仍然要走完漏斗，不能直接判未找到

第二步：合并四层候选，去重
把思想/情感/结构/表象四层的Top-10候选合并，去重（按global_id或行号），得到候选池（通常15-30个）。
对每个候选标注：它出现在哪几层的检索结果里。
出现在多层的候选优先级更高，但不代表一定通过——仍然要走完漏斗。

第三步：思想层筛选（排除主题完全不沾边的+触发条件检查）
用分析卡给的"思想层分析"和"触发条件"，逐个检查候选池里的每个候选：
- 候选的核心思想（生存哲学/价值观/潜台词）和拍子的思想层分析一致吗？
  - 不一致 → 淘汰，写"思想层淘汰：核心思想不同（具体原因）"
  - 一致 → 进入触发条件检查
- 【触发条件检查】（v6.3新增）：
  · 拍子的思想触发条件是什么？（从分析卡的"触发条件"字段读取）
  · 候选的思想触发条件是什么？（读候选原文判断）
  · 触发条件一致 → 通过，进入下一层
  · 触发条件不一致 → 淘汰，写"思想层淘汰：触发条件不同（拍子是XXX，候选是XXX）"
- 注意：思想层是最宽松的，大部分候选能通过，通过不代表什么
- 触发条件检查是思想层的附加关卡，防止"思想看起来像但处境完全不同"的候选混过去

输出：思想层筛选结果（通过X个，淘汰Y个，每个淘汰候选写原因）

第四步：情感层筛选（排除情绪走向不对的）
用分析卡给的"情感层分析"，在第三步通过的候选中，逐个检查：
- 候选的核心情绪和情绪变化和拍子的情感层分析一致吗？
- 不一致 → 淘汰，写"情感层淘汰：情绪走向不同（具体原因）"
- 一致 → 通过，进入下一层

输出：情感层筛选结果（通过X个，淘汰Y个）

第五步：结构层筛选（排除动作链不同的）
用分析卡给的"结构层分析"，在第四步通过的候选中，逐个检查：
- 候选的动作链和叙事功能和拍子的结构层分析一致吗？
- 不一致 → 淘汰，写"结构层淘汰：动作链不同（具体原因）"
- 部分一致 → 标记"结构层部分匹配：缺XXX"，保留但降级
- 一致 → 通过，进入下一层
- 注意：结构层是关键分水岭，很多候选在这里被淘汰

输出：结构层筛选结果（通过X个，部分匹配Y个，淘汰Z个）

第六步：表象层筛选（排除具体动作不对的）
用分析卡给的"表象层分析"，在第五步通过的候选中，逐个检查：
- 候选的具体动作、身体细节、场景细节和拍子的表象层分析一致吗？
- 不一致 → 淘汰，写"表象层淘汰：具体动作不同（具体原因）"
- 部分一致 → 标记"表象层部分匹配：缺XXX"，保留但降级
- 一致 → 通过
- 注意：表象层是最严格的，完全通过的候选很少

输出：表象层筛选结果（通过X个，部分匹配Y个，淘汰Z个）

第七步：读完整原文+两项检查+选主选
对第六步通过的候选（通常0-2个），每个都：
1. 按行号从原txt提取完整段落（至少500字）
2. 通读全文
3. 主体检查：做这个动作的人，是主角还是对手？和拍子的主体一致吗？
   - 一致 → 通过
   - 不一致 → 淘汰，写"主体检查不通过：做动作的人是XXX，拍子要的是XXX"
4. 核心动作检查：拍子要的那个核心动作，原文里真的发生了吗？
   - 发生了 → 通过
   - 没发生 → 淘汰，写"核心动作检查不通过：原文没有发生XXX这个动作"
5. 功能画像检查：3-5条硬条件，逐条核对
6. 验证问题检查：1-3个是/否问题

选主选：
- 两项检查都通过的候选 → 选为主选
- 如果有多个通过 → 选四层匹配度最高的（优先结构层和表象层都完全通过的）
- 备选：两项检查都通过的第二候选，或结构层完全通过但表象层部分匹配的候选
- 未找到的触发条件（满足任一即触发）：结构层筛选后通过/部分匹配为0，或表象层筛选后通过/部分匹配为0，或通过四层的候选在两项检查后全部不通过
- 触发未找到时 → 写"未找到"，列出每个候选卡在哪一层或哪项检查
- 注意："思想层都搜不到"不是未找到的标准，思想层最宽松，通用主题一定搜得到

五、绝对禁止
======================================================================

1. 禁止走到思想层和情感层就判"高度匹配"——必须走到最后一步
2. 禁止写"主选方向"而不给行号和原文——主选必须有行号和原文
3. 禁止用"思想主题一样"替代"核心动作发生"——核心动作必须真的发生了
4. 禁止把100%通过率当成功——正常通过率是60%-80%，100%意味着偷懒了
5. 禁止只看三层摘要就选主备选——必须自己读完整原文验证
6. 禁止只看前100字预览——必须读完整原文（至少500字）
7. 禁止跳过候选漏斗筛选记录——每个候选的每层淘汰原因必须写出来
8. 禁止标"最近似"硬贴——找不到就写未找到，列出每个候选卡在哪一层
9. 禁止凭记忆仿写原文——原文必须从txt读取
10. 禁止把"背景介绍"当"实际发生"——要选动作真的发生了的段落
11. 禁止主体反了——做动作的人必须和拍子的主体一致
12. 禁止自己做深度分析——分析卡已经做了，你直接读取产物
13. 禁止修改分析卡的分析结论——如果分析报告有问题，标注"分析报告可能有误"
14. 禁止去全量向量库重新检索——分析卡已经给了四层候选，直接从这些候选里选
15. 禁止不读原文就信任分析卡的摘要——摘要是参考，你必须自己读原文验证
16. 禁止核心动作检查不过还给"部分匹配"——你在核心动作检查里写了"无……的核心动作""无……动作"，该候选就只能判"未找到"，不得用"主题相似""表象相似"兜底升回部分匹配。"部分匹配"的前提是核心动作发生了但细节有出入；核心动作根本没发生就是未找到
17. 禁止同一段原文（同一本书同一行号）同时作为两个拍的主选——发现两个拍指向同一段原文时，保留核心动作更贴合的一拍为主选，另一拍降级处理：若该段对另一拍只是通用主题相似，改判未找到并在原因里写明"共用原文已让出"；选主选前先全局检查16拍的主选行号有无重复
18. 禁止候选漏斗淘汰记录与最终判定自相矛盾——你在淘汰记录/读原文验证里写了什么结论，最终判定就必须跟它一致。写了"无核心动作"就不能给部分匹配，写了"主体反了"就必须在匹配度里标注"主体反了"
19. 禁止文件头部统计与结尾汇总口径不一致——写完正文后，头部"匹配结果统计"和结尾"匹配结果汇总"必须用同一组数字，且与正文逐拍判定一致；改判任何一拍后必须同步改头部和结尾两处

1. P1修正：简化筛选记录，只写淘汰者原因，通过者不写长记录
   - 问题：v6.0要求对每个候选、每一层都写完整记录，20个候选×4层=80条判断记录，16个拍就是上千条，执行到第3个拍就会开始省略

   - 问题：v6.0写的是"思想层都搜不到→才考虑未找到"，这个条件几乎永远不会触发，因为思想层是最宽松的，通用主题在15本金庸里一定搜得到
