## P0立即执行改进点（汇总）

### 1. 系统提示词优化（方案1+4）
- 明确跑批任务标准流程：第1步status_monitor+notify_feishu，第2步batch_run，第3步等待并检查进度
- 为每个关键工具添加完整调用示例
- stuck_prompt个性化：跑批任务必须先调用batch_run

### 2. 工具结果标准化（方案9）
- 所有工具返回统一格式：{ok: bool, summary: str, details: dict, error: str}
- batch_run工具返回started字段时，execute方法正确处理

### 3. 多API容错架构（方案5）
- 主API（谷歌中转）+ 备用API（智谱4.5-air）
- 主API连续失败3次自动切换
- API健康检查脚本

### 4. 状态持久化（方案7）
- Agent状态写入logs/agent_state.json
- 进程崩溃后可恢复

### 5. 任务级模型选择（方案8）
- 简单任务：2.5-flash-lite
- 中等任务：3.5-flash
- 复杂任务：2.5-pro
- 超复杂：三个标签

### 6. Token智能优化（方案8）
- 工具结果超过500字自动用智谱4.0摘要
- 每10步压缩早期消息
