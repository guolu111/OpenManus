### 补充1：Mac上用uv安装（比pip快5-10倍，必须写）
`ash

### 补充2：路径兼容层（不做的话Mac上大概率路径报错）
- **问题**：代码里硬编码\路径分隔符，Mac上是/
- **建议**：全局搜索替换所有硬编码路径为os.path.join()或pathlib.Path
- **重点检查**：config.toml里的路径、工具脚本里的文件路径、日志路径
- **示例**：D:\360Downloads\... → 用Path.home() / "..."或配置文件指定

### 补充3：浏览器路径配置（Mac Chrome路径不同）
- **Windows默认**：C:\Program Files\Google\Chrome\Application\chrome.exe
- **Mac默认**：/Applications/Google Chrome.app/Contents/MacOS/Google Chrome
- **建议**：config.toml里加rowser_path字段，按平台配置
- **三标签bridge**：multi_bridge.py里的Chrome启动路径也要按平台判断

### 补充4：配置迁移清单（迁移时必须重新配置的项）
| 配置项 | Windows值 | Mac需要改 | 说明 |
|---|---|---|---|
| API key | 已配置 | 直接复制 | 所有API key可以直接迁移 |
| browser user-data-dir | Windows路径 | 改Mac路径 | Chrome用户数据目录 |
| 飞书webhook | 已配置 | 直接复制 | webhook URL不变 |
| 3标签bridge端口 | 8010 | 不变 | 端口配置跨平台通用 |

### 补充5：Mac特有注意事项
- **权限**：Mac首次运行需要给终端"完全磁盘访问权限"（系统设置→隐私与安全性）

## 【补充建议·MAC后台常驻优化】（2026-09-06 联网搜索补充，只做加法）

> 来源：macOS launchd官方文档、多个Mac部署Python服务实战教程
> 原则：只追加，原有方案不动，由统帅自行决定是否采纳
> 核心：用Mac官方的 launchd + .plist 机制实现后台常驻、开机自启、崩溃自动重启

### 为什么用launchd（而不是nohup/tmux）

| 方案 | 关终端退出 | 崩溃重启 | 开机自启 | 日志管理 | 推荐度 |
|---|---|---|---|---|---|
| nohup | 不退出 | ❌ 不重启 | ❌ | 手动 | ⭐⭐ |
| tmux/screen | 不退出 | ❌ 不重启 | ❌ | 手动 | ⭐⭐⭐ |
| supervisor | 不退出 | ✅ 重启 | 需配置 | ✅ | ⭐⭐⭐⭐ |
| **launchd（官方）** | **不退出** | **✅ 自动重启** | **✅ 原生支持** | **✅ 自动重定向** | **⭐⭐⭐⭐⭐** |

launchd是macOS官方的服务管理机制，生产级稳定，不需要额外安装软件。

### 需要常驻的3个进程

| 进程 | 作用 | plist文件名 |
|---|---|---|
| feishu_bot.py | 飞书网关（收消息+调度统帅） | com.openmanus.feishu.plist |
| multi_bridge.py | 3标签桥接（端口8010） | com.openmanus.bridge.plist |
| 任务看板/探针 | 监控体系 | com.openmanus.monitor.plist |

### plist模板（以feishu_bot.py为例）

创建文件：~/Library/LaunchAgents/com.openmanus.feishu.plist

`xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.openmanus.feishu</string>

    <key>ProgramArguments</key>
    <array>
        <string>/Users/YOUR_USERNAME/OpenManus/.venv/bin/python</string>
        <string>-u</string>
        <string>/Users/YOUR_USERNAME/OpenManus/feishu_bot.py</string>
    </array>

    <key>WorkingDirectory</key>
    <string>/Users/YOUR_USERNAME/OpenManus</string>

    <key>RunAtLoad</key>
    <true/>

    <key>KeepAlive</key>
    <true/>

    <key>StandardOutPath</key>
    <string>/Users/YOUR_USERNAME/OpenManus/logs/launchd_feishu.log</string>

    <key>StandardErrorPath</key>
    <string>/Users/YOUR_USERNAME/OpenManus/logs/launchd_feishu.err.log</string>

    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/Users/YOUR_USERNAME/OpenManus/.venv/bin:/usr/local/bin:/usr/bin:/bin</string>
        <key>PYTHONUNBUFFERED</key>
        <string>1</string>
    </dict>
</dict>
</plist>
`

**关键字段说明**：
- ProgramArguments：必须用.venv的python绝对路径，不能用系统python
- WorkingDirectory：必须指定，否则相对路径全错
- RunAtLoad=true：登录后自动启动
- KeepAlive=true：崩溃后自动重启（核心优势）
- StandardOutPath/StandardErrorPath：日志自动重定向到文件
- EnvironmentVariables.PATH：launchd的PATH和终端不一样，必须显式设置

### 一键部署脚本（install_mac_services.sh）

`ash
#!/bin/bash
# OpenManus Mac后台服务一键部署脚本
# 用法：bash install_mac_services.sh

set -e

# 配置（根据实际情况修改）
OPENMANUS_DIR="C:\Users\mis/OpenManus"
VENV_PYTHON="/.venv/bin/python"
LAUNCHAGENTS_DIR="C:\Users\mis/Library/LaunchAgents"
LOGS_DIR="/logs"

# 创建日志目录
mkdir -p ""
mkdir -p ""

# 生成plist的函数
generate_plist() {
    local name=
    local script=
    local plist_file="/com.openmanus..plist"

    cat > "" << EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.openmanus.</string>
    <key>ProgramArguments</key>
    <array>
        <string></string>
        <string>-u</string>
        <string>/</string>
    </array>
    <key>WorkingDirectory</key>
    <string></string>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
    <key>StandardOutPath</key>
    <string>/launchd_\.log</string>
    <key>StandardErrorPath</key>
    <string>/launchd_\.err.log</string>
    <key>EnvironmentVariables</key>
    <dict>
        <key>PATH</key>
        <string>/.venv/bin:/usr/local/bin:/usr/bin:/bin</string>
        <key>PYTHONUNBUFFERED</key>
        <string>1</string>
    </dict>
</dict>
</plist>
EOF
    echo "✅ 已生成: "
}

# 生成3个服务的plist
generate_plist "feishu" "feishu_bot.py"
generate_plist "bridge" "三个标签/multi_bridge.py"
generate_plist "monitor" "任务看板/status_probe.py"

# 加载服务
echo ""
echo "=== 加载服务 ==="
for name in feishu bridge monitor; do
    plist_file="/com.openmanus..plist"
    launchctl unload "" 2>/dev/null || true
    launchctl load ""
    echo "✅ 已加载: com.openmanus."
done

echo ""
echo "=== 部署完成 ==="
echo "查看状态: launchctl list | grep openmanus"
echo "查看日志: tail -f /launchd_feishu.log"
echo "停止服务: launchctl unload /com.openmanus.feishu.plist"
echo "启动服务: launchctl load /com.openmanus.feishu.plist"
`

### 3个坑（提前知道，避免踩坑）

1. **Python路径必须绝对路径**
   - ❌ 错误：python feishu_bot.py（用了系统python）
   - ✅ 正确：/Users/xxx/OpenManus/.venv/bin/python -u feishu_bot.py
   - 用which python在激活的虚拟环境里查看绝对路径

2. **WorkingDirectory必须指定**
   - launchd的默认工作目录是/，不是脚本所在目录
   - 不指定的话，所有相对路径（config/、logs/、.learnings/）全错

3. **PATH环境变量必须显式设置**
   - launchd的PATH非常精简（只有/usr/bin:/bin）
   - 找不到uv、python、playwright等命令
   - 在plist的EnvironmentVariables里显式设置PATH

### Mac特有注意事项

- **权限**：首次运行需要给终端"完全磁盘访问权限"（系统设置→隐私与安全性→完全磁盘访问权限）
- **Chrome自动化**：Mac需要给Chrome"辅助功能"权限，否则Playwright控制不了
- **防火墙**：Mac防火墙可能拦截本地端口（8010/7860等），首次运行允许即可
- **睡眠**：Mac合盖睡眠后服务会暂停，需要在"节能"设置里关闭"合盖睡眠"（或用caffeinate保持唤醒）
