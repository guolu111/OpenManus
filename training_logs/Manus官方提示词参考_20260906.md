# Manus官方系统提示词参考（2026-09-06 从leaked-system-prompts获取）

## Agent Loop（核心循环）
1. Analyze Events: 理解用户需求和当前状态
2. Select Tools: 选择下一个工具调用
3. Wait for Execution: 等待工具执行结果
4. Iterate: 每次迭代只选一个工具，重复直到完成
5. Submit Results: 通过消息工具发送结果
6. Enter Standby: 任务完成后进入空闲状态

## 20个Modules规则
1. intro - 能力介绍（6大类任务）
2. language_settings - 语言设置（默认英文，跟随用户）
3. system_capability - 系统能力（消息/沙箱/浏览器/代码/部署）
4. event_stream - 事件流（Message/Action/Observation/Plan/Knowledge/Datasource）
5. agent_loop - 智能体循环（6步）
6. planner_module - 规划模块（编号伪代码，状态更新）
7. knowledge_module - 知识模块（最佳实践参考）
8. datasource_module - 数据源模块（权威API优先）
9. todo_rules - 待办规则（todo.md清单，实时更新）
10. message_rules - 消息规则（notify/ask，首次简短确认）
11. file_rules - 文件规则（用文件工具避免转义，积极保存中间结果）
12. info_rules - 信息规则（API>搜索>内部知识，访问原始页面）
13. browser_rules - 浏览器规则（必须用浏览器工具，主动探索链接）
14. shell_rules - Shell规则（-y/-f，&&链接，管道，bc/Python计算）
15. coding_rules - 编码规则（保存到文件再执行，搜索解决方案）
16. deploy_rules - 部署规则（expose port，0.0.0.0监听）
17. writing_rules - 写作规则（连续段落，详细，引用来源）
18. error_handling - 错误处理（验证工具名参数，尝试修复，多种失败后报告）
19. sandbox_environment - 沙箱环境（Ubuntu 22.04，Python3.10，Node20）
20. tool_use_rules - 工具使用规则（必须function calling，不编造工具）

## Browser Use恢复循环机制（借鉴）
1. 连续失败计数器：consecutive_failures >= max_failures时停止
2. 升级恢复策略：
   - 1st timeout: NEW_TAB（开新标签，保持记忆）
   - 2nd timeout: SCROLL_AND_WAIT（滚动等待，可能懒加载）
   - 3rd timeout: REFRESH_PAGE（强制刷新）
   - 4th timeout: GO_BACK（返回上一页）
   - 5th+: STOP_TASK（不可恢复，报告失败）
3. 无进度检测器：URL+accessibility-tree hash+工具集指纹检测卡住
4. 失败重放：enable_replay_on_failure，max_replay_attempts=2
5. 不同策略重试：selector_mode/css/坐标/视觉多种方式
