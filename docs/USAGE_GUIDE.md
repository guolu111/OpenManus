# 使用方法指南

> 本文档深入介绍OpenManus统帅的各种功能和使用技巧。

## 一、基础使用

### 1.1 启动和退出

```bash
# 启动
source .venv/bin/activate
python main.py

# 退出
输入 /exit 或按 Ctrl+C
```

### 1.2 基本对话

启动后直接用自然语言下达任务，例如：

```
帮我写一个Python脚本，统计当前目录下所有txt文件的行数
```

统帅会自动：
1. 分析需求
2. 制定计划
3. 调用工具执行
4. 返回结果

### 1.3 常用命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `/help` | 查看帮助 | `/help` |
| `/status` | 查看当前状态 | `/status` |
| `/memory` | 查看记忆 | `/memory` |
| `/todo` | 查看任务清单 | `/todo` |
| `/clear` | 清空上下文 | `/clear` |
| `/exit` | 退出 | `/exit` |

## 二、核心功能

### 2.1 文件操作

统帅可以直接操作本地文件：

```
# 读取文件
帮我读取 README.md 的内容

# 编辑文件
把 config.toml 里的 model 改成 gemini-2.5-pro

# 创建文件
帮我创建一个 test.py，内容是 print("Hello World")

# 批量处理
把当前目录下所有 .txt 文件改成 .md
```

### 2.2 代码执行

```
# 执行Python代码
帮我执行这段代码：import os; print(os.listdir('.'))

# 执行Shell命令
帮我列出当前目录的文件，按大小排序
```

### 2.3 网页浏览和搜索

```
# 搜索
帮我搜索 "OpenManus 安装教程"

# 访问网页
帮我访问 https://github.com/FoundationAgents/OpenManus，看看README内容

# 网页版AI标签
用智谱清言帮我分析这段文字的情感倾向
```

### 2.4 飞书通知

配置飞书webhook后，统帅会自动发送通知：

```
# 配置飞书
帮我配置飞书通知，webhook是 https://open.feishu.cn/open-apis/bot/v2/hook/xxx

# 手动发送
帮我发一条飞书消息：任务已完成
```

通知时机：
- 任务开始
- 每步完成
- 任务完成
- 出错告警
- API用量告警

### 2.5 多模型协同

统帅会自动根据任务复杂度选择模型：

| 任务类型 | 使用模型 | 说明 |
|---------|---------|------|
| 规划/决策/复杂推理 | Gemini-2.5-pro | 最聪明，额度少省着用 |
| 正常执行/工具调用 | Gemini-2.5-flash-lite | 主力，速度快 |
| 简单搬运/JSON处理 | 智谱GLM-4.5-air | 不占自己额度 |
| 最简单分类/去重 | 硅基GLM-4-9B | 免费，最轻量 |
| 深度思考/交叉验证 | 3标签网页版（智谱/千问/豆包） | 最新旗舰模型 |

### 2.6 知识库检索

遇到复杂问题，统帅会自动检索DeepSeek知识库：

```
# 手动检索
帮我检索知识库里关于"任务拆解"的示例

# 查看统计
python knowledge_base/deepseek_thinking/search.py --stats
```

## 三、高级功能

### 3.1 批量跑批

```
# 跑批金庸小说第22章
帮我跑批鹿鼎记第22章，模式是纯数据

# 查看跑批进度
帮我查看跑批进度
```

跑批5步流程：
1. 初始化（状态更新+用量统计+飞书通知）
2. 启动跑批（返回PID和日志路径）
3. 监控进度（每30秒更新）
4. 完成（状态更新+用量统计+飞书通知）
5. 整理报告

### 3.2 3标签桥接

3个网页版AI标签通过桥接服务统一调用：

```
# 检查桥接健康状态
帮我检查3标签桥接状态

# 重启桥接（如果异常）
帮我重启3标签桥接
```

桥接端口：8010
支持标签：智谱清言、千问国际版、豆包

### 3.3 自我学习和进化

统帅会自动记录错误和经验：

```
# 查看历史错误
帮我查看 .learnings/ERRORS.md

# 查看已学到的经验
帮我查看 .learnings/LEARNINGS.md

# 生成日报
帮我生成今日复盘报告
```

学习机制：
- 遇到错误自动记录到 ERRORS.md
- 修复成功后记录到 LEARNINGS.md
- 每次任务开始先查历史错误，避免重踩坑
- 每天最后一个任务自动生成复盘报告

### 3.4 梦境模块

统帅在空闲时会自我反思：

```
# 查看梦境日志
帮我查看 logs/dreaming/ 目录
```

梦境功能：
- 总结当天经验
- 发现潜在问题
- 生成改进建议
- 更新记忆库

## 四、使用技巧

### 4.1 下达任务的正确姿势

❌ 不好的指令：
```
帮我处理一下这些文件
```

✅ 好的指令：
```
帮我把当前目录下所有 .txt 文件读取内容，统计每个文件的行数，然后把结果保存到 result.csv
```

要点：
- 明确目标（要做什么）
- 明确范围（哪些文件/目录）
- 明确输出（保存到哪里，什么格式）
- 明确约束（有什么限制）

### 4.2 复杂任务拆解

对于复杂任务，可以让统帅先制定计划：

```
帮我制定一个计划：把这个Python项目改造成支持Mac和Windows双平台
```

统帅会先输出计划，你确认后再执行。

### 4.3 中断和修改

执行过程中可以随时打断：

```
停一下，刚才的方法不对，应该用正则表达式而不是字符串替换
```

统帅会立即停止当前操作，根据新指令调整。

### 4.4 查看进度

长时间任务可以随时问进度：

```
现在进度怎么样了？
```

统帅会返回：
- 当前步骤
- 已完成步骤
- 预计剩余时间
- 遇到的问题

## 五、配置优化

### 5.1 模型轮转配置

在 `config/config.toml` 中配置四模型轮转：

```toml
[llm]
model = "gemini-2.5-flash-lite"
rotation_models = [
    "gemini-2.5-flash-lite",
    "gemini-3.5-flash",
    "gemini-2.5-pro",
    "glm-4.5-air"
]
rotation_threshold = 800  # 超过800次自动轮转
```

### 5.2 工具掩码

可以根据任务类型临时禁用某些工具：

```
这次任务只允许使用文件操作工具，不要用浏览器
```

### 5.3 上下文管理

长对话会占用大量上下文，可以定期清理：

```
/clear  # 清空上下文，保留记忆
```
