# API分层架构设计

> 本文档说明OpenManus统帅的API分层体系，合理分配各模型的用途，避免额度浪费，最大化整体效能。

## 一、我们的API资产清单

### 1.1 谷歌中转API（gcli.ggchan.dev）—— 统帅主力大脑

| 模型 | 日额度 | 智慧程度 | 适用场景 |
|------|--------|---------|---------|
| **gemini-2.5-pro** | 95次/天 | ⭐⭐⭐⭐⭐ 旗舰 | 最高级决策、战略规划、跨领域综合、复杂推理 |
| **gemini-3.5-flash** | 190次/天 | ⭐⭐⭐⭐ 强 | 中等复杂度决策、任务拆解、结果汇总 |
| **gemini-2.5-flash-lite** | 950次/天 | ⭐⭐⭐ 主力 | 常规决策、工具调用、日常调度、内容生成 |

**特点**：
- 长上下文：1M tokens，能处理大型文档和代码库
- 多模态：支持图片理解
- 已实现四模型轮转，避免429限流
- 轮转比例：40%:20%:20%:20%（2.5用2次→3.5用1次→pro用1次→智谱air用1次）

### 1.2 智谱清言API —— 编程主力 + 数据搬运

| 模型 | 额度 | 智慧程度 | 适用场景 |
|------|------|---------|---------|
| **glm-4.5-air** | 1200万token | ⭐⭐⭐⭐ 强 | 编程、代码生成、中等复杂度推理、内容生成 |
| **glm-4-flash** | 免费 | ⭐⭐ 轻量 | 简单问答、格式转换、批量处理 |

**特点**：
- GLM-4.5综合得分63.2分，全球第三，国产第一
- 编程能力介于Claude 3.7~4之间
- 355B MoE架构，131K上下文
- 不占谷歌额度，适合干粗活重活

### 1.3 硅基流动API —— 免费搬运工

| 模型 | 额度 | 智慧程度 | 适用场景 |
|------|------|---------|---------|
| **glm-4-9b** | 免费 | ⭐ 基础 | 纯JSON处理、去重、分类、简单数据搬运、格式转换 |

**特点**：
- 开源小模型，完全免费
- 智慧程度较低，只能干最简单的粗活
- 调用速度快，适合批量处理

### 1.4 DeepSeek知识库 —— 常驻专家（非API）

| 资产 | 大小 | 价值 | 调用方式 |
|------|------|------|---------|
| **经验包（第九章）** | 35行提示词 | ⭐⭐⭐⭐⭐ 核心 | 已融入统帅系统提示词，每次调用自动生效 |
| **完整知识库** | 98MB语料 | ⭐⭐⭐⭐ 重要 | 通过search.py检索工具，需要时自动检索 |
| **105条精选示例** | 0.5MB | ⭐⭐⭐ 参考 | 6大分类，按场景查询 |

**特点**：
- DeepSeek最有价值的是它的"思考方式"，已经被我们蒸馏成本地资产
- 3673条思考过程蒸馏出6大思维模式：需求分析·3步法、任务拆解·逐项核对法、决策判断·对比择优法、错误处理·根因追踪法、回复组织·结构化输出法、思维纪律·防重复循环
- 不需要调用API，不消耗额度，常驻本地
- DeepSeek的API可作为备用，但核心价值已经本地化

### 1.5 3标签网页版 —— 深度思考专家会诊

| 标签 | 模型 | 智慧程度 | 状态 |
|------|------|---------|------|
| **智谱清言网页版** | 最新旗舰 | ⭐⭐⭐⭐⭐ | ✅ 可用 |
| **千问国际版网页版** | Qwen最新 | ⭐⭐⭐⭐⭐ | ✅ 可用 |
| **豆包网页版** | 字节最新 | ⭐⭐⭐⭐⭐ | ⚠️ 待激活（测试失败） |

**特点**：
- 网页版才能用最新旗舰模型，API版可能不是最新
- 适用：复杂方案优化、交叉验证、深度思考、创意生成
- 通过ask_tag.py和ask_enhancer.py调用
- 有头浏览器模式，防封控

### 1.6 汉堡云（备用）

| 项目 | 说明 |
|------|------|
| 地址 | hanbaoyu.ggff.net |
| 额度 | 约500次/天 |
| 稳定性 | 不稳定，成功率77.3% |
| 用途 | 仅作为紧急备用，主力API全部故障时使用 |

## 二、API六层架构

```
┌─────────────────────────────────────────────────────────┐
│  第一层：统帅决策层（大脑）                                │
│  Gemini 2.5 Pro / 3.5 Flash / 2.5 Flash-Lite            │
│  功能：最高决策、任务拆解、结果汇总、日常调度              │
│  额度：95+190+950次/天，四模型轮转                       │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  第二层：角色卡执行层（专业大脑）                          │
│  每张角色卡有自己的偏好模型                                │
│  分析→Gemini Flash | 生成→GLM-4.5 | 学生→GLM-4-9b     │
│  小助手→GLM-4.5 | 脚本→GLM-4.5 | ...                    │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  第三层：粗活重活层（搬运工）                              │
│  GLM-4-9b（硅基免费）+ GLM-4-Flash（智谱免费）          │
│  + GLM-4.5-air（智谱1200万token）                        │
│  功能：纯JSON处理、去重、分类、数据搬运、格式转换         │
│  特点：不占谷歌额度，免费/低成本，可批量调用              │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  第四层：深度思考层（专家会诊）                            │
│  3标签网页版：智谱清言 + 千问国际版 + 豆包（待激活）      │
│  功能：复杂方案优化、交叉验证、深度思考、创意生成         │
│  特点：网页版最新旗舰模型，有头浏览器防封控               │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  第五层：世界书常驻层（知识库）                            │
│  DeepSeek经验包（第九章提示词）+ 完整知识库（98MB）      │
│  功能：6大思维模式常驻、3673条思考过程可检索             │
│  特点：本地化、不消耗额度、常驻生效                       │
└──────────────────────────┬──────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────┐
│  第六层：备用层（应急）                                    │
│  汉堡云 + 其他中转API                                     │
│  功能：主力API全部故障时的紧急备用                        │
│  特点：额度少、不稳定，仅应急使用                         │
└─────────────────────────────────────────────────────────┘
```

## 三、角色卡与API匹配表

| 角色卡 | 首选模型 | 备用模型 | 理由 |
|--------|---------|---------|------|
| **文件夹管理员（统帅）** | gemini-2.5-pro | gemini-2.5-flash-lite | 最高决策需要最强模型，常规调度用主力 |
| **分析** | gemini-2.5-flash-lite | glm-4.5-air | 分析不需要最强模型，主力够用 |
| **生成** | glm-4.5-air | gemini-2.5-flash-lite | GLM-4.5编程能力强，不占谷歌额度 |
| **老师** | gemini-2.5-flash-lite | glm-4.5-air | 教学需要稳定输出，主力更稳 |
| **学生** | glm-4-9b | glm-4-flash | 试错成本最低，免费模型随便用 |
| **匹配** | glm-4.5-air | glm-4-9b | 匹配分类不需要最强模型 |
| **小助手** | glm-4.5-air | glm-4-9b | 数据搬运不占谷歌额度，智谱更合适 |
| **每天更新** | gemini-2.5-flash-lite | glm-4.5-air | 连载业务需要稳定，主力更可靠 |
| **脚本** | glm-4.5-air | gemini-2.5-flash-lite | 脚本编写GLM-4.5编程能力强 |

## 四、API调用决策树

```
任务来了
  ↓
是最高级决策/战略规划/跨领域综合？→ 是 → gemini-2.5-pro（95次/天，省着用）
  ↓ 否
是中等复杂度决策/任务拆解/结果汇总？→ 是 → gemini-3.5-flash（190次/天）
  ↓ 否
是常规决策/工具调用/日常调度？→ 是 → gemini-2.5-flash-lite（950次/天，主力）
  ↓ 否
是编程/代码生成/脚本编写？→ 是 → glm-4.5-air（智谱，不占谷歌额度）
  ↓ 否
是纯JSON处理/去重/分类/简单搬运？→ 是 → glm-4-9b（硅基，免费）
  ↓ 否
是复杂方案优化/交叉验证/深度思考？→ 是 → 3标签网页版（智谱/千问/豆包）
  ↓ 否
是需要参考DeepSeek思考方式？→ 是 → 检索知识库（search.py，不消耗额度）
  ↓ 否
默认 → gemini-2.5-flash-lite（主力）
```

## 五、额度保护策略

### 5.1 谷歌中转额度保护（最重要）

| 策略 | 说明 |
|------|------|
| **四模型轮转** | 已实现，避免单模型429限流 |
| **Pro模型省着用** | 95次/天，仅用于最高级决策，常规任务不用 |
| **粗活外包** | 数据搬运、JSON处理、去重分类全部外包给智谱/硅基，不占谷歌额度 |
| **深度思考用网页版** | 复杂方案优化用3标签网页版，不消耗API额度 |
| **知识库本地化** | DeepSeek思考方式已蒸馏成本地知识库，检索不消耗额度 |

### 5.2 智谱额度保护

| 策略 | 说明 |
|------|------|
| **air模型为主** | 1200万token额度，足够日常使用 |
| **flash模型免费** | 简单任务用glm-4-flash，完全免费 |
| **避免重复调用** | 相同输入缓存结果，避免重复调用 |

### 5.3 硅基额度（免费，无需保护）

- glm-4-9b完全免费，可批量调用
- 适合：去重、分类、格式转换、简单数据搬运

## 六、DeepSeek的定位：常驻世界书，不常驻API

### 6.1 为什么DeepSeek不常驻API？

1. **核心价值已本地化**：DeepSeek最有价值的是它的"思考方式"，3673条思考过程已经蒸馏成：
   - 第九章经验包（6大思维模式，常驻提示词）
   - 完整知识库（98MB语料，可检索）
2. **我们已有更强的主力**：谷歌中转Gemini系列 + 智谱GLM-4.5，能力足够
3. **额度有限**：DeepSeek API额度有限，不如留给紧急情况

### 6.2 DeepSeek的正确使用方式

| 资产 | 使用方式 | 消耗额度？ |
|------|---------|-----------|
| **第九章经验包** | 已融入统帅提示词，每次调用自动生效 | ❌ 不消耗 |
| **完整知识库** | 需要时通过search.py检索，参考思考方式 | ❌ 不消耗 |
| **105条精选示例** | 按场景查询，参考具体案例 | ❌ 不消耗 |
| **DeepSeek API** | 仅作为备用，主力全部故障时使用 | ✅ 消耗 |

### 6.3 世界书与DeepSeek的关系

```
世界书（共享信息空间）
├── 通用规则（8将军共享共识）
├── 通气公告（新规则/新经验）
├── 决议台账（已固化的规则）
└── DeepSeek思考知识库（常驻专家）
    ├── 6大思维模式（经验包）
    ├── 3673条思考过程（可检索）
    └── 105条精选示例（按分类查询）
```

DeepSeek知识库是世界书的一部分，作为"常驻专家"供所有角色卡检索参考，但不需要调用API。

## 七、实施路线图

### Phase 1：基础框架（当前）
- ✅ 四模型轮转已实现
- ✅ 智谱/硅基助手工具已实现
- ✅ 3标签网页版桥接已实现
- ✅ DeepSeek知识库已建立
- 🔄 角色卡体系正在开发

- ⏳ 每张角色卡配置首选/备用模型
